# Shorot

[![Tests](https://github.com/DavidSalmon13/shorot/actions/workflows/test.yml/badge.svg)](https://github.com/DavidSalmon13/shorot/actions/workflows/test.yml)

**A real-time multiplayer party-game platform for groups playing in the same room.** Everyone joins from their own phone with a 4-character room code. The phones act as private hands and controllers, and the group plays together out loud.

**Live:** [imposter.shorots.com](https://imposter.shorots.com)

## Games

| Game | What it is |
|---|---|
| **Imposter** | Everyone gets the same secret word except the imposter, who only gets a hint. The word and hint are generated by an LLM. |
| **Codenames** | Two teams race to find their words on a 5×5 grid from spoken one-word clues. The grid is LLM-generated. |
| **10 Seconds** | Stop your stopwatch as close to exactly 10.000 s as you can; the furthest player is eliminated each round. |
| **Menifot** | A card game where one deck is split across 2–3 shared poker boards and each player secretly splits their hand across them. |
| **Music Timeline** | Teams build a chronological timeline of songs. The LLM picks each song, and the DJ team plays it out loud. |
| **All-In or Fold** | A 6-seat Omaha variant: on your turn you shove everything or fold. Includes real side pots and a staged board reveal. |
| **Mind Meld** | Guess how one specific friend will answer an absurd, personalized, LLM-generated estimation question. |
| **Bluff** | Deals real cards privately to each phone and tracks counts around a virtual table for an in-person bluffing game. |
| **Warfront** | A two-team real-time strategy game on a generated grid map, with fog of war, A\* pathfinding, high ground, an economy and production. |

## Features

- **Real-time rooms** over Socket.io. Each player gets private state (roles, cards, fogged map views) while the shared state goes to the whole room.
- **Accounts** with Google sign-in, lifetime game history, ratings and badges, stored in PostgreSQL.
- **Virtual tokens and betting** on Bluff. These are play money only; there is no real currency.
- **Admin dashboard** and an owner-only daily usage stats page.
- **Installable PWA**, with automatic client reload when a new version is deployed.
- **Survives restarts**: room state is saved to disk and restored on redeploy.

## Tech stack

**Backend:** Node.js, Express, Socket.io, PostgreSQL (`pg`), Google OAuth (`google-auth-library`), OpenAI API
**Frontend:** Vanilla JavaScript, HTML, CSS (no build step)
**Testing / CI:** Node's built-in test runner (`node --test`), GitHub Actions
**Hosting:** Railway

## Architecture

```
server.js               Express + Socket.io bootstrap, routes, persistence timers
server/
  gameRegistry.js       Registers every game module behind one contract
  roomStore.js          In-memory rooms, per-game state namespaces
  lobby.js              Joining, hosts, reconnects, shared scoreboard
  persistence.js        Saves and restores room state across restarts
  db.js, accounts.js    PostgreSQL access, Google sign-in, game history
  ratings.js, badges.js, betting.js, stats.js, admin.js
  games/                One module per game (+ warfrontEngine.js, a pure simulation engine)
  lib/                  OpenAI client, seeded RNG, shuffling, input validation
public/                 Static client: index.html, js/games/*, js/shared/*
migrations/             SQL migrations for PostgreSQL
tests/                  Unit tests per game, plus a shared harness with socket/room fakes and an OpenAI mock
docs/                   Per-game specs, implementation plans and design mockups
```

- **Pluggable games.** Each game is a self-contained module that owns its state under its own namespace and registers its socket handlers through `gameRegistry.js`. Adding a game doesn't touch the others.
- **Server-authoritative.** All game logic runs on the server. Clients only render state and send intents, so players can't see each other's private data.
- **Warfront** runs a fixed-tick simulation loop per room and sends each player a fog-of-war-filtered snapshot 5 times per second. The engine is a pure module, so it's tested in isolation.
- **Optional services.** The app runs without a database (results just aren't recorded) and without Google sign-in configured.
- **Private sticker photos.** The built-in stickers are photos of the original friend group. They're served only to devices unlocked with a crew code; everyone else gets neutral generated avatars from the same URLs (`server/crew.js`).

## Running locally

Requires Node.js 18+.

```bash
git clone https://github.com/DavidSalmon13/shorot.git
cd shorot
npm install
cp .env.example .env   # add OPENAI_API_KEY; the other variables are optional and documented in the file
npm start              # http://localhost:3000
```

Open the URL in several browser tabs (or on phones on the same network) to play with multiple players.

## Tests

```bash
npm test
```

300+ tests cover each game's server-side rules, the lobby, ratings and the admin API. They run on every push and pull request via GitHub Actions.
