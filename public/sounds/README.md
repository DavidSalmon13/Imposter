Tap sounds. Drop short animal clips here (`.mp3`, `.ogg`, `.wav` or `.m4a`,
ideally under ~1s and ~30 KB each); every file in this folder is picked up at
server start and one is played at random on each button press. With no files
here, taps fall back to the synthesized click in `public/js/fx.js`.

Only add clips you have the right to use (public domain / CC0, or CC-BY with
credit listed below).
